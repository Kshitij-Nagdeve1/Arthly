🌿 Arthly — Personal Finance Tracker

Spend Smart. Build Better.

A sleek, dark-themed personal finance web app designed to track expenses, manage budgets, and gain financial insights.

🌐 Live Demo

🔗 Live Application: https://arthly.onrender.com

✨ Features

Dashboard Overview: Real-time visibility into Monthly Budget, Total Spent, and Remaining Balance.

Category Insights: Dynamic breakdown of spending across key categories (Food, Travel, Shopping, Utilities).

Expense Management: Add, edit, filter, and search transactions easily.

Authentication: Secure user sign-up and log-in.

Botanical Dark Theme: Minimalist UI with dark slate (#0B131E) and mint green (#71DDA0) accents.

🛠️ Tech Stack

Frontend: HTML5 (EJS Templating), CSS, JavaScript

Backend: Node.js / Express

Database: MongoDB

🚀 Quick Local Setup

# Clone the repository
git clone https://github.com/Kshitij-Nagdeve1/arthly.git

# Install dependencies
npm install

# Run the project
node --env-file=.env app.js
